# follow咪 · 健身跟练打卡

把跟练视频收拢到一处，按计划督促你练完，并记下坚持了多久。

不用注册，不用登录。打卡记录、身体数据、上传的视频都留在你自己的设备上，不会上传到任何地方。

添加到手机主屏幕后，它会像独立 App 一样全屏打开，断网也能使用。

## 解决的问题

- 跟练视频散落在各个平台，收藏夹存了一堆，但「今天练哪个、练了没有」没人管。
- 常见的打卡应用要注册账号、把数据传到服务器，还要看广告。
- 视频平台的「收藏」记的是想练什么，记不下练了几次、连续坚持了多久。

follow咪 把这些收拢到一屏：今天做什么、还剩几次、点开就练、练完盖章。

## 主要功能

### 今日

顶部是一只趴着的猫咪，头顶云朵里报着当天的日期时间和「还有 N 个任务没有完成哦」。任务按你设的周期自动算出今天要练几次、还剩几次。

上传的视频播完会自动打卡，也可以手动标记。打卡完成时会盖上一枚猫爪印。

### 任务

两种类型：

- **上传视频** —— 从设备里选一个视频文件，卡片会自动截取封面。
- **链接 / 嵌入** —— 粘贴视频地址，用平台的官方播放器播放。

每个任务单独设周期：每天练 N 次，或者每周指定几天、每天 N 次。

### 记录

- 累计打卡次数、连续天数、本周与本月完成率。
- 打卡日历有周、月、年三种视图。周和月视图里，每打卡一次显示一只猫爪印；年视图里，每格按当月打卡次数铺爪印，练得越多越密。
- 身体数据：体重、腰围等指标可自行增删，按日期录入，用折线图看长期变化。

### 设置

任务管理、数据导出与导入、重置。

## 视频怎么放进来

**方式一：上传本地视频**

从相册或文件里选一个视频。这是唯一支持「播完自动打卡」的方式，横屏全屏播放也没问题。视频只存在你自己的设备上。

**方式二：粘贴链接**

| 平台 | 支持情况 |
| --- | --- |
| 哔哩哔哩 | 粘贴视频页地址即可，自动识别编号，用官方播放器内嵌播放 |
| b23.tv 短链 | 短链里不含视频编号，前端无法还原，请改用完整的视频页地址 |
| 抖音、小红书等 | 平台不允许被嵌入，会提供「打开原链接」跳转过去，看完回来手动打卡 |

链接类任务无法判断视频什么时候播完，需要手动标记完成。

## 隐私与安全

- **没有服务器，也没有账号。** 打卡记录、身体数据、上传的视频全部存在你自己设备的浏览器里，不会上传到任何地方。
- **不收集任何信息。** 没有统计埋点，没有广告，没有第三方追踪。
- 页面加载的只是应用本身的静态文件。只有当你点开某个链接类任务时，才会连接对应的视频平台。
- 应用外壳会被缓存，**断网也能打开使用**。
- 数据只在本机，因此**清除浏览器数据会丢掉全部记录**，建议定期在「设置」里导出备份。

## 装到 iPhone 主屏幕

1. 用 **Safari** 打开应用地址（微信、QQ 等内置浏览器无法添加）。
2. 等页面加载完整，点屏幕底部中间的「分享」按钮。
3. 在列表里选「添加到主屏幕」，确认。
4. 桌面出现 follow咪 图标。点开就是全屏应用，没有浏览器地址栏。

## 数据备份

在「设置」里可以把任务、打卡记录、身体数据导出成一个 JSON 文件，换设备或重装后导入即可恢复。

需要注意：**上传的视频文件和封面不包含在备份里**，恢复后要重新上传；链接类任务保存的地址会完整保留。

## 已知限制

- 抖音、小红书等平台不允许嵌入播放，只能跳转原链接后手动打卡。
- 链接类任务无法自动检测播放结束，需要手动标记；上传视频可以自动检测。
- B 站部分视频因版权或地区限制，官方播放器可能提示无法播放，可点「打开原链接」观看。
